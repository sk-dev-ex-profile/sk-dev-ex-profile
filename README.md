# Алексей Андриянов — Backend-разработчик

Пишу на Python. Мне нравится разбираться в том, как устроена серверная часть:
от обработки запроса до сохранения данных и ответа пользователю.
В учебных проектах работаю с Flask и SQL, пишу тесты и настраиваю запуск через Docker.

Ищу первую Backend-позицию, где смогу работать над прикладными задачами,
участвовать в код-ревью и развиваться рядом с более опытными разработчиками.

## Что умею

- **Python и Flask:** обработка HTTP-запросов, работа с формами, проверка входных данных и обработка ошибок.
- **SQL и SQLite:** проектирование небольших схем, запросы и транзакции для связанных изменений.
- **Тестирование:** тесты серверной логики и веб-обработчиков с `unittest`, проверка ошибочных сценариев.
- **Инструменты:** Git, Docker Compose, Ruff и документация по запуску проекта.

## Проекты

### [Book Loan Tracker — учёт выдачи книг](https://github.com/sk-dev-ex-profile/book-loan-tracker)

Учебное приложение для учёта книг, выданных знакомым: кому отдали книгу,
вернули ли её и какие выдачи были раньше. Есть веб-интерфейс и команды терминала.

В проекте представлены работа с базой, общая логика для двух интерфейсов
и тесты ошибок. Например, неудачная выдача не должна оставлять частично
сохранённые данные.

**Стек:** Python · Flask · Jinja · SQLite · unittest · Docker Compose.
